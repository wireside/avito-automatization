## Три независимые интеграции

| Система              | Что получаем                                                                      | Авторизация                                                               | Для чего нужна проекту                                                          |
| -------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Национальный каталог | Карточка по GTIN, атрибуты, классификация, изображения, разрешительные документы  | API Key либо Bearer-токен ГИС МТ; не передавать оба одновременно          | Распознать название, артикул, размер и цвет при первом скане                    |
| True API             | Статусы и владелец КИ, история, зарегистрированные документы, квитанции, выгрузки | Токен после аутентификации с УКЭП; ключ НК не заменяет этот токен         | Проверить приёмку, отгрузку, вывод и возврат, сверить юридические события       |
| СУЗ API 3.0          | Эмиссия новых КМ, получение кодов, отчёты о нанесении, квитанции                  | `clientToken`, `omsId`; для получения токена используется `omsConnection` | Будущая перемаркировка/собственное производство, если такой процесс понадобится |

В True API «публичный» означает доступ для пользователей **с токеном**, а не анонимный запрос. В документации отдельно выделен доступ «без токена»: [True API, PDF с. 9-10](sources/true-api.pdf#page=9).

Для легпрома код группы — `lp`, числовой идентификатор — `1`: [True API, с. 739](sources/true-api.pdf#page=739). Не путать строковый код, числовой ID и идентификатор категории Национального каталога.

## Очерёдность реализации

1. **Каталог при сканировании.** Неизвестный GTIN → `GET /v3/product` НК → сохранение исходных атрибутов и происхождения → сопоставление модели и варианта. Сохранённые карточки повторно используются при следующих приёмках. При отсутствии данных остаётся явный неразрешённый вариант.
2. **Документ поставки и стоимость.** Импорт исходного УПД/XML или подтверждённого контракта Saby; связь строки документа с конкретным КИ и закупочной ценой. Из НК закупочная цена не получается. Скан создаёт физическую приёмку отдельно от подписания документа.
3. **Юридическая проверка.** Проверка КИ, владельца, допустимого состояния и обработки входящего документа. Успешное распознавание карточки не выпускает товар из карантина.
4. **Отгрузка и возврат.** Единственный выбранный канал ЧЗ, сохранённый состав отправления, durable operation, подпись локальным агентом при необходимости, проверка документа и конечного состояния каждого КИ.
5. **Сверка и аналитика.** Пакетные выгрузки КИ, ошибок и отклонений; собственные остатки PostgreSQL сверяются с юридическими сведениями, но не заменяются ими.
6. **Условное развитие.** Агрегаты, разрешительные документы, перемаркировка, собственные карточки и эмиссия. Их наличие в документации не включает эти процессы в текущий MVP.

## Что уже установлено документацией

- НК `product` предназначен для опубликованных и архивных карточек; `feed-product` — для своих карточек или доступа через субаккаунты. Для обычного распознавания товара поставщика начинать с `product`, а не с перечисления собственных карточек.
- True API описывает для легпрома `fullName`, `type`, `size`, `color`, `textileType`, `structure`, `gender`, `country`, `model` и другие поля: [с. 831-832](sources/true-api.pdf#page=831). Реальный возврат зависит от заполнения карточки, метода и прав аккаунта.
- `POST /api/v4/true-api/product/info` принимает до 1000 GTIN, но возвращает только карточки с `goodTurnFlag=true` и `goodMarkFlag=true`; это ограничение нельзя переносить на все методы НК.
- API Key НК не является универсальным ключом к статусам КИ, документам True API, СУЗ и Saby.
- Прочитать УПД, подписать УПД, принять физические пары и получить подтверждение юридического перехода — разные действия.

## Границы полученного пакета

Архив содержит шесть PDF, 1881 страницу. Сохранены все исходники без изменений; нормализованы только имена файлов. Версии: НК 5.68 от 28.09.2026, True API 747.0 от 21.10.2026, СУЗ API 3.0.40 / редакция 67 от 24.09.2026. Документация Saby, схемы его авторизации и реальный УПД поставщика в архив не входят.

Шесть OpenAPI-файлов составлены в проекте по PDF: полный индекс 180 действующих и 18 исторических операций, исходные описания методов, таблицы и ссылки на оригиналы. Это не официальная Swagger-выгрузка ЦРПТ и не полная типизированная схема всех тел. Для каждой операции указаны источник, страницы, уровень описания и предупреждение о побочных эффектах. Перед реализацией читать соответствующие страницы и проверять обезличенные реальные ответы.
